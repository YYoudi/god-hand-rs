God Hand PC
JournalRoadmapCode

Development journal

The aim is a faithful PC port of God Hand that can later be remastered. The active work continues the evaluated LasVola base in the separate GPL god-hand-pc project, with a personal ISO. Original behavior comes first; PC enhancements are separate and reversible, not reasons to rewrite the entire game in another engine.

The independent Rust/Bevy work is paused and preserved, not complete. Third-party runtime results are labeled separately. This page records actual checks, original comparisons and what is still unknown.
